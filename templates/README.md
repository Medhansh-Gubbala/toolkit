# templates/

Intentionally empty. Pre-built code trees rot with every Next.js/shadcn release, so /recipe scaffolds through the official CLIs (`create-next-app@latest`, `shadcn init`) instead — those never go stale. Per-template structure (pages, sections, notes) lives in `../recipes/*.json`.

If a real reusable template ever earns its keep (same custom code copied into 3+ projects), it goes here then — not before.
